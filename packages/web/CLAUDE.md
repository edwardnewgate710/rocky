## Design Context

This package has captured design context for the `impeccable` skill:

- `PRODUCT.md` — platform (web), target users (competitive/rated players), positioning, brand personality, and anti-references.
- `DESIGN.md` — the visual system ("The Grandmaster's Study"): color tokens, typography, elevation, and component rules.

Read both before making UI changes in this package. Run `/impeccable` for design-related tasks (critique, polish, live iteration, etc.) rather than freehand styling.

The **mode** (Persuade / Operate / Read / Experience) is chosen per surface and recorded in that
surface's brief — it is not a project-wide setting. The play surfaces here (board, lobby, profile)
are **Operate**: the visitor is completing a task, so scanability, consistency and native
expectations outrank expression. This replaced the retired `## Register` axis in Impeccable v4.
