## Design Context

This package has captured design context for the `impeccable` skill:

- `PRODUCT.md` — register (product), platform (web), target users (competitive/rated players), positioning, brand personality, and anti-references.
- `DESIGN.md` — the visual system ("The Grandmaster's Study"): color tokens, typography, elevation, and component rules.

Read both before making UI changes in this package. Run `/impeccable` for design-related tasks (critique, polish, live iteration, etc.) rather than freehand styling.
